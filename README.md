# Автотесты для сервиса Stellar Burgers

Проект представляет собой комплексную автоматизацию тестирования космического фастфуда **Stellar Burgers**. Тесты написаны на языке **Python** с использованием библиотеки **Selenium WebDriver** и фреймворка **Pytest**.

## ��� Функциональные проверки

В проекте реализованы следующие тестовые сценарии:

1. **Регистрация:**
    * Успешная регистрация с валидными данными.
    * Проверка ошибки при вводе некорректного пароля (менее 6 символов).
2. **Вход в аккаунт:**
    * Вход по кнопке «Войти в аккаунт» на главной странице.
    * Вход через кнопку «Личный кабинет».
    * Вход через ссылку в форме регистрации.
    * Вход через ссылку в форме восстановления пароля.
3. **Личный кабинет:**
    * Переход в личный кабинет по клику на соответствующую кнопку.
    * Переход из личного кабинета в конструктор по клику на кнопку «Конструктор» и на логотип сервиса.
    * Выход из аккаунта по кнопке «Выйти».
4. **Раздел «Конструктор»:**
    * Проверка навигации по разделам ингредиентов: «Булки», «Соусы», «Начинки».

## ��� Технологический стек

* **Python 3.x** — основной язык разработки.
* **Selenium WebDriver** — управление браузером (Google Chrome).
* **Pytest** — фреймворк для организации и запуска тестов.
* **WebDriverWait** — механизм явных ожиданий для стабильности тестов.

## ��� Структура проекта

* `tests/` — директория с файлами тестов, разделенных по функциональности:
    * `test_registration.py` — тесты регистрации.
    * `test_login.py` — тесты различных точек входа.
    * `test_profile.py` — тесты личного кабинета и выхода.
    * `test_constructor.py` — тесты навигации в конструкторе.
* `locators.py` — описание XPATH-локаторов всех элементов страниц.
* `conftest.py` — конфигурация фикстур (инициализация драйвера, генерация данных, пре-логин).
* `.gitignore` — список исключений для Git (venv, __pycache__).
* `README.md` — описание проекта и инструкции.

## ⚙️ Особенности реализации (conftest.py)

* **Фикстура driver:** Инициализирует WebDriver для Google Chrome перед каждым тестом.
* **Генерация данных:** Создает уникальный email в формате: `Timur.Sharipov.39.XXX@yandex.ru`.
* **Фикстура registered_user:** Автоматически регистрирует нового пользователя через интерфейс и возвращает его на главную страницу для начала теста.
* **Фикстура login_user:** Выполняет полный цикл авторизации, подготавливая состояние браузера для тестов профиля.
* **Автономность:** Каждый тест открывает отдельное окно браузера и завершается командой `driver.quit()`.
